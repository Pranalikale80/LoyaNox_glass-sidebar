# 🪟 Glass Sidebar

A modern and responsive **Glass Sidebar** built using **React**, **Vite**, **Tailwind CSS**, and **shadcn/ui**.

## ✨ Features

* Glassmorphism sidebar design
* Responsive layout
* Smooth UI
* Modern and clean interface

## 🛠️ Tech Stack

* React
* Vite
* Tailwind CSS
* shadcn/ui
* Lucide React

